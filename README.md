## Lessons Learned About Clean Code
1. **DRY Principle (Don’t Repeat Yourself)**  
   Reusing functions and avoiding duplicate logic makes the code easier to maintain and debug.

2. **Single Responsibility Principle**  
   Each function or class should do exactly one thing — for example, separating file reading from data display.

3. **Readable and Self-Documenting Code**  
   Using clear variable names, formatted outputs, and docstrings helps both developers and reviewers understand the purpose of each component.

4. **Error Checking and Validation**  
   Ensuring user input and file handling are properly validated prevents runtime errors and unexpected behavior.

5. **Modularisation**  
   Dividing the project into multiple small files (modules) like `project.py` and `project_management.py` improves clarity and reusability.
